# Hazard Detection and Survey System

## About the Project
A remotely controlled robot designed to inspect potentially dangerous areas and detect hazards.

## Features
- Bluetooth-based robot control
- Obstacle detection using an ultrasonic sensor
- Fire detection using a flame sensor
- Automatic motor stop when fire is detected
- LED warning indicator
- Forward, backward, left and right movement

## Hardware Components
- Arduino
- HC-05 Bluetooth Module
- Ultrasonic Sensor
- Flame Sensor
- Motor Driver
- 2 DC Motors
- LED
- Robot Chassis and Wheels

## Technologies Used
- Arduino C++
- Embedded Systems
- Bluetooth Communication

## Code
Main program: `hazard_rover.ino`

## Applications
- Remote inspection of hazardous areas
- Basic fire hazard detection
- Search and rescue support

## Future Improvements
- Camera-based monitoring
- Human detection
- Live video streaming
